# Adaptive Learning Platform - Règles de contribution

Merci de contribuer à ce projet ! Voici comment faire :

## Code de Conduite
Toute contribution doit respecter la courtoisie et le respect mutuel.

## Comment Contribuer

### 1. Fork et Clone
```bash
git clone https://github.com/YOUR_USERNAME/adaptive-learning-platform.git
cd adaptive-learning-platform
```

### 2. Créer une Branche
```bash
git checkout -b feature/votre-fonctionnalite
```

### 3. Commits
- Utilisez des messages clairs et descriptifs
- Format: `type(scope): description`
- Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

Exemple:
```bash
git commit -m "feat(auth): add two-factor authentication"
```

### 4. Tests
```bash
npm run test
npm run test:coverage
```

### 5. Linting
```bash
npm run lint
```

### 6. Pull Request
- Décrivez les changements clairement
- Référencez les issues liées
- Vérifiez que tous les tests passent

## Standards de Code

✅ TypeScript strict
✅ Tests unitaires requises
✅ 70%+ de couverture de code
✅ Prettier formaté
✅ ESLint validé
